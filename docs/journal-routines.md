# Journal des routines de contenu

Une ligne par passage de chaque routine (production, contrôle, réparation, relecture, questions, contrôle du droit), y compris quand il n'y avait rien à faire. Les routines d'Arnaud l'écrivent ; celles de Vincent peuvent le faire aussi. Chaque ligne est commitée avec le travail qu'elle décrit, pour que l'historique git dise qui a fait quoi, quand et pourquoi on s'est arrêté.

Format : `AAAA-MM-JJ HH:MM | routine | source | résultat`. La source est `arnaud` ou `vincent` (le compte qui fait tourner la routine).
